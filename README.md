# 💼 IT HubPro — учёт проектов и финансов IT-компании

Система для суперадмина и рабочих: проекты, автоматическое распределение денег
(20% / 5% / доля рабочего / деньги компании), серверы, продления и уведомления.

## Стек
- **Backend:** Django 6 + Django REST Framework + JWT (SimpleJWT), SQLite
- **Frontend:** Vue 3 + Vite + Pinia + Vue Router
- **Валюта:** тенге (₸), интерфейс на русском

---

## Запуск

### 1. Backend (порт 8000)
```bash
cd backend
../venv/Scripts/python.exe manage.py migrate      # первый раз
../venv/Scripts/python.exe manage.py seed         # демо-данные + суперадмин
../venv/Scripts/python.exe manage.py runserver 127.0.0.1:8000
```

### 2. Frontend (порт 5173)
```bash
cd frontend
npm install        # первый раз
npm run dev
```

Открыть **http://localhost:5173**

## Возможности

### Суперадмин
- **Дашборд** — общая картина: поступления, деньги компании, фонды 20% и 5%, выплаты рабочим.
- **Проекты** — создание проекта: выбор рабочего, название, тип оплаты (разовая/ежемесячная),
  доля рабочего, галочка **«куплен сервер»** (логин/пароль/срok месяц-год/оплата из фонда),
  галочка **«дан аванс»** с живым расчётом распределения, даты старта/дедлайна/беты.
- **Рабочие** — создание рабочих со своим логином.
- **Финансы** — три «корзины» денег: компания, фонд 20%, фонд 5% (приход/расход/баланс).
- **Серверы** — покупка и продление, оплата из выбранного фонда, срок «месяц/год».
- **Продления** — ежемесячные проекты, кнопка «Оплачено» сдвигает срок на месяц.
- **Колокольчик** — уведомления: сервер за 7 и за 1 день; продление проекта за 3 дня и в день оплаты.

### Рабочий
- **Мои проекты** — назначенные проекты, свои даты, серверы.
- **Заработок** — своя доля по каждому проекту и суммарно.

## Финансовая логика
Оплата проекта идёт **этапами**: `старт` → `бета` → `сдача` (плюс, при необходимости,
`ежемесячное обслуживание`). С каждого поступления автоматически отделяется:
- **фонд 1** (по умолчанию 20%) и **фонд 2** (по умолчанию 5%) — ставки и названия настраиваются;
- **доля рабочего** — фиксированные суммы за **бету** и **сдачу** (старт — без доли);
- **остаток** → деньги компании.

Пример: платёж за бету **300 000 ₸**, рабочему за бету 50 000 →
60 000 (20%) + 15 000 (5%) + 50 000 (рабочему) + 175 000 (компании).

Ежемесячная оплата распределяется так же, но **без доли рабочего** (договариваются отдельно).

Рабочий отмечает фактическую сдачу проекта — система показывает, сдал он
**раньше**, **вовремя** или **позже** дедлайна.

Логика покрыта тестами:
```bash
cd backend && ../venv/Scripts/python.exe manage.py test
```
